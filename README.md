# Komentář k zákonu č. 148/2023 Sb., o jednotném environmentálním stanovisku

Otevřený komentář k zákonu o jednotném environmentálním stanovisku — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; jednotné environmentální stanovisko k záměrům podle stavebního zákona, žádost, lhůty, platnost, předběžná konzultace, příslušné orgány a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2023-00148_2025-08-01`.
